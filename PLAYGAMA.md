# Playgama Bridge: интеграция

Игра работает через [Playgama Bridge](https://wiki.playgama.com/playgama/bridge-sdk/getting-started) v2 (Plain JS). YouTube Playables SDK полностью удалён.

## Подключение

- `index.html` загружает `https://bridge.playgama.com/v2/stable/playgama-bridge.js` — это единственный внешний ресурс; всё остальное лежит в архиве.
- `public/playgama-bridge-config.json` попадает в корень билда рядом с `index.html`. В нём задан `minimumDelayBetweenInterstitial: 60`.
- `src/platform.js` — единственная точка работы с `window.bridge`. Игра стартует только после `bridge.initialize()` (таймаут 15 с; если Bridge недоступен, игра запускается без сохранений и рекламы).

## Обязательные шаги Bridge

| Требование | Реализация |
| --- | --- |
| Язык | `bridge.platform.language` читается один раз после инициализации. `ru` → русский, остальные → английский. |
| Сохранения | Только `bridge.storage`: один ключ `skincare_progress`, чтение одним вызовом `get(['skincare_progress'], false)`, запись `set([key],[json])`. localStorage напрямую не используется. Записи последовательные, при ошибке повтор через 5 с, хранится последний снимок. |
| Пауза и звук | Начальные `platform.isAudioEnabled` / `platform.isPaused` применяются сразу, затем `AUDIO_STATE_CHANGED` и `PAUSE_STATE_CHANGED`. Bridge сам отслеживает сворачивание вкладки, blur/focus и рекламу; игра останавливает цикл, ввод, музыку и эффекты. Обработчик видимости Phaser вырезан при сборке, чтобы паузой управлял один источник. |
| game_ready | Отправляется, когда меню уровней интерактивно. Дополнительно: `level_started` и `level_completed` с номером уровня. |
| Interstitial | При переходах: запуск уровня, Next, Replay/Restart/Retry, возврат в меню, вход/выход из бонус-игр. Частоту ограничивает Bridge (60 с, плюс начальная задержка платформы); отклонённый показ сразу даёт `failed` и не блокирует переход. |
| Rewarded | Только по кнопке с иконкой видео и понятной наградой. Награда выдаётся только при состоянии `rewarded`; закрытие раньше не даёт ничего. Награды — бонусы (монеты, подсказки, пропуски, подарки, VIP-уровни, которые можно пропустить); прохождение кампании от них не зависит. |

## Локализация

`src/i18n.js` содержит словарь EN→RU и шаблоны для динамических строк (числа, склонения: «1 монета / 2 монеты / 5 монет»). Перевод применяется в одном месте — в `Phaser.GameObjects.Text#setText`, а также в DOM-подписях (загрузка, ошибки, aria-label). Шрифт Nunito подключён с кириллическими начертаниями 800/900. Логотип «Skincare ASMR» — название игры, оно не переводится.

## Проверки

С запущенным `npm run dev`:

- `node scripts/bridge-browser.mjs` — двойник Bridge: язык, одно чтение хранилища, `game_ready`, пауза/звук, interstitial перед уровнем, throttled interstitial, rewarded с `rewarded` и без него, сохранение и перезагрузка.
- `node scripts/audio-test.mjs`, `node scripts/daily-entry-test.mjs` — используют `scripts/bridge-double.mjs`.

Это проверки контрактов на двойнике и на mock-платформе Bridge, **не проверка реальной рекламы Playgama**. После загрузки архива в кабинет Playgama нужно открыть опубликованную ссылку и проверить показы рекламы, сохранение между сессиями и паузу при сворачивании на телефоне и ПК.
